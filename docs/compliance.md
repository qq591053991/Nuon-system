# 合规能力对照

本系统把医疗器械质量体系中“必须做对”的规则固化在软件里。下表说明每条要求在系统中由什么功能、以什么方式保证。

> 说明：软件只是质量体系的工具。正式用于受监管的生产前，企业仍需按自身质量体系完成计算机化系统验证（CSV：URS / IQ / OQ / PQ），并编写相应的 SOP。下表可作为 URS 与验证用例的起点。

## 国内《医疗器械生产质量管理规范》（按章节）/ ISO 13485:2016

| 要求 | 系统实现 | 强制方式 |
|---|---|---|
| 文件控制（ISO 13485 4.2.4；规范“文件管理”） | BOM、工艺路线（含测试规格）分 **草稿 / 已发布 / 已作废**；发布需电子签名；发布后只能“升版”并填写 ECN 号；旧版自动作废 | 已发布版本接口层拒绝修改 |
| 记录控制（4.2.5） | 所有业务数据自动审计追踪；库存流水只增不改；电子签名记录不可删除 | ORM 层统一拦截，无需各功能自行实现 |
| 采购控制 / 供方评价（7.4.1；规范“采购”） | 合格供方名录：状态 + 资质有效期 | 非“合格供方”或资质过期 → 采购订单**无法审批** |
| 采购产品验证（7.4.3） | 收货自动进入“待检”状态并生成 IQC 检验单，按 GB/T 2828.1 自动给出抽样方案（字码、n、Ac/Re） | 待检库存**不能被领料或发货**；判定需电子签名 |
| 生产过程控制（7.5.1；规范“生产管理”） | 工单下达时**快照**已发布的 BOM 与工艺；工位终端显示 SOP 编号与作业指导 | 只能使用已发布版本；后续工艺变更不影响已下达工单 |
| 每批/每台的生产记录（7.5.1 末段；QMSR 下的 DHR 要求） | **电子 DHR**：物料批次、工序记录、操作人、设备、测试数据、NCR、放行签名一页汇总、可打印 | 自动汇编，无需手工整理 |
| 标识（7.5.8） | 生产批号、序列号自动生成；库存按质量状态标识（待检/合格/不合格/冻结） | 状态驱动业务可用性 |
| 可追溯性（7.5.9） | 批次 + 序列号双层追溯；关键件（如医用电源）批次绑定到单台；正向/反向追溯页面 | 关键件工序未扫码不能过站；扫描未领用批次被拒 |
| 产品防护（7.5.11） | 有效期管理、FEFO 先到期先出、湿敏 LED 防潮柜库位 | 过期批次禁止领用 |
| 监视和测量设备控制（7.6） | 设备台账、校准周期、校准记录、到期预警 | 校准过期/不合格的仪器**禁止用于报工** |
| 产品的监视和测量 / 放行（8.2.6；规范“质量控制”中的产品放行） | 工序测试数据按规格上下限**自动判定**；成品入库为“待放行”；QA 审核 DHR 检查清单后电子签名放行 | 未放行产品**禁止发货**；检查项未通过不能放行 |
| 不合格品控制（8.3；规范“不合格品控制”） | 测试不合格/检验不合格**自动开 NCR**；评审处置需 QA 电子签名；返工后重新测试并标记返工 | NG 产品处置前不能继续过站；**生产过程不合格品不允许让步放行** |
| 纠正和预防措施（8.5.2 / 8.5.3） | CAPA：根因、纠正、纠正措施、预防措施、有效性验证；与 NCR 关联 | 未填根因/措施不能进入验证；关闭需有效性结论 + 电子签名 |
| 委托生产（注册人制度下的受托生产） | 客户 = 注册人；质量协议编号与有效期；成品归属品牌客户；**客供料货主隔离** | 客供料只能用于该客户工单、不能采购；产品只能销售给其品牌客户 |

## 美国 FDA

| 要求 | 系统实现 |
|---|---|
| 21 CFR 820（QMSR，2026-02-02 起以引用方式纳入 ISO 13485:2016） | 同上表 |
| 21 CFR Part 11 §11.10(e) 审计追踪 | 系统自动生成、带时间戳、记录操作人与字段前后值；任何角色都无法通过系统修改或删除 |
| §11.10(d) 访问控制 / §11.10(g) 权限检查 | 账号 + 角色权限点，后端每个接口校验 |
| §11.50 签名显示 | 签名记录包含签名人全名、时间、签名含义（如“产品放行（DHR审核批准）”），在 DHR 中显示 |
| §11.200 电子签名组成 | 已登录会话 + 再次输入本人密码；签名与具体记录关联 |
| UDI（21 CFR 830 / GUDID） | 成品维护 UDI-DI（GTIN-14，系统校验 GS1 校验位）；生产时生成 UDI-PI：(11)生产日期 (17)失效日期 (10)批号 (21)序列号 |

## UDI（中国《医疗器械唯一标识系统规则》）

- UDI-DI：物料主数据 `gtin` 字段（GS1 GTIN-14）
- UDI-PI：工单下达时为每台产品生成，HRI 格式例：`(01)06970000000017(11)261112(10)B261112001(21)RL32611120001`
- 发货时逐台记录序列号 → 客户，满足追溯与召回需要
