# 从金蝶迁移实施方案

目标：**4–6 周完成切换，业务不停摆**。推荐“业务系统整体替换、财务总账可暂留金蝶”的路线：
采购、销售、库存、生产、质量全部在本系统运行；如果财务部门习惯金蝶总账，可先每月导出应收应付/出入库汇总给财务做凭证，后续再做凭证接口。

## 阶段计划

| 周 | 阶段 | 主要工作 | 交付物 |
|---|---|---|---|
| 第 1 周 | 蓝图确认 | 梳理现有流程与单据；确认编码规则、仓库库位、角色分工；确认产品的工序与测试规格 | 业务蓝图、角色权限表 |
| 第 2 周 | 基础数据迁移 | 从金蝶导出客户、供应商、物料、BOM；清洗后用“数据导入”功能导入；工艺工程师补录工艺路线与测试规格，电子签名发布 | 主数据导入报告 |
| 第 3 周 | 培训 + 模拟运行 | 按角色培训（每个角色 1 小时以内）；用 1–2 个真实订单在测试环境走通全流程 | 培训签到、模拟运行记录 |
| 第 4 周 | 期初 + 切换 | 月末盘点；导入期初库存（批次、有效期、库位）；在途采购/销售订单录入；正式切换 | 期初库存核对表 |
| 第 5–6 周 | 并行与验证 | 金蝶只读保留；按 CSV 要求完成 IQ/OQ/PQ；收集问题快速迭代 | 验证报告、问题清单关闭 |

## 数据导入（系统菜单：系统与合规 → 数据导入）

导入顺序：**供应商 / 客户 → 物料 → BOM → 期初库存**。每个文件只要有一行出错，整份文件回滚，修正后重新导入即可（按编码自动“新增或更新”，可反复导入）。

系统兼容金蝶 K/3 Cloud / 星空 常见导出列名，也可下载系统模板填写：

| 导入对象 | 金蝶导出列（任一即可识别） | 系统字段 |
|---|---|---|
| 物料 | 编码 / 物料编码 / FNumber | 物料编码 |
| | 名称 / 物料名称 / FName | 物料名称 |
| | 规格型号 | 规格 |
| | 物料属性（外购→原材料、自制→成品、委外→半成品）/ 物料类别 | 物料类别 |
| | 基本单位 / 计量单位 | 单位 |
| | 安全库存、固定提前期 / 采购提前期、参考成本 / 标准成本、保质期 | 同名字段 |
| | 启用批号管理 / 启用序列号管理（是/否） | 批次/序列号管理 |
| | 默认供应商（编码或名称） | 默认供应商 |
| 客户 / 供应商 | 编码、名称、简称、联系人、联系电话、通讯地址、纳税登记号、结算币别 | 同名字段 |
| BOM | 父项物料编码、BOM版本、子项物料编码、用量:分子、用量:分母、损耗率(%)、位号 | 草稿 BOM（需工程师审核后电子签名发布） |
| 期初库存 | 物料编码、库位编码、批号、数量、生产日期、有效期至 | 期初入库（合格状态） |

注意事项：

1. **BOM 导入后为草稿**，必须由工程师核对后电子签名发布才能用于生产（受控文件要求）。
2. 金蝶中的“仓位”需先在系统“库位”中建好同名编码。
3. 客供料（客户提供的彩盒、说明书等）在物料中设置“货主客户”，期初导入时会自动记到该客户名下。
4. 供应商导入时默认“待评审”，请质量部根据合格供方名录把合格的供应商改为“合格供方”并维护资质有效期，否则无法下采购订单。
5. 成品请补充 注册证号、管理类别、UDI-DI（GTIN）、序列号前缀。

## 角色与培训要点

| 角色 | 日常只需要用的功能 |
|---|---|
| 销售 | 销售订单（新建/确认）、发货申请、订单进度 |
| PMC | MRP 运算 → 一键转单；工单下达 |
| 采购 | 采购订单（MRP 建议已自动生成草稿）→ 审批 |
| 仓管 | 收货、领料过账（系统已推荐批次）、完工入库、发货过账、盘点 |
| 操作员 | **只用“工位终端”**：扫码 → 录数 → 提交 |
| 质检 / QA | 待办里的 IQC、NCR、DHR 放行 |
| 财务 | 应收应付、收付款、账龄 |
