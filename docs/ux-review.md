# 岗位体验评审（2026-11-12）

5 个代理分别扮演工厂岗位，用真实浏览器（Playwright）完成各自的日常工作，评价“好用、顺手”而非“能用”。
截图与脚本：`scratchpad/ux-a`（销售/计划/采购）、`ux-b`（仓管 PDA）、`ux-c`（产线操作员/工艺）、`ux-d`（质检/QA）、`ux-e`（厂长/财务/管理员）。
编号：A=销售计划采购，WH=仓管，C=工位/工艺（F01…），D=质量（#1…），E=厂长财务管理员。

## 一、总体结论

- **主流程都能走通**；做得好的：追溯一码到底（召回评估 10 秒）、发货扫码、FEFO 拣料、单据步骤条与“下一步”提示、强制改密与空闲超时、导入整单回滚、电子签名含义清楚、工位键盘主流程（扫码→3 值→回车约 1 秒/台）。
- **离“好用”还差的 6 个共性问题**：
  1. 扫码枪在下拉框里回车会选错（库位、订单、工单都出现过）；全局搜索扫码回车不跳转。
  2. 列表普遍不能导出 Excel、不能排序、单据不能打印（金蝶用户最不习惯）。
  3. 菜单、工作台、待办不分岗位；操作员能看到财务数据；待办跳转不带筛选。
  4. 手机/PDA 不可用：侧栏常驻、固定列挤没内容、弹窗超出屏幕。
  5. 已确认/已过账的单据不能改、不能反审核/红冲。
  6. 电子签名弹窗密码框不自动聚焦、回车不提交（QA 每天签 10–15 次）。
- **会产生错误数据的 P0（必须先修）**：工位回车跳转随机失灵导致测量值拼接写入 DHR；测试项编码可重复；扫码选错库位/订单/工单；收货库位无校验；盘点快照导致重复调账；订单生成工单与 MRP 转工单重复；重跑 MRP 重复采购；期初库存重复导入翻倍；预置演示账号公开密码。

## 二、修复分组（按代码区域）

### G0 通用组件（协调者完成）
| 编号 | 问题 | 方案 |
|---|---|---|
| WH-01/A/E-16 | 扫码枪在远程下拉框回车选中第一项 | RemoteSelect 扫码安全：回车时按输入精确匹配编码，未返回前不自动选第一项，查无报错 |
| D#1/#15 | 签名弹窗不聚焦、回车不提交、密码错关闭弹窗 | 自动聚焦密码框；回车提交；密码错误保留弹窗并提示 |
| A5/D4/E-04/WH-08 | 列表不能导出 | 通用“导出 Excel”（按当前筛选导出全部） |
| E-11/D3/WH-08 | 打印丢列、无页码、打印出界面元素 | 通用打印样式与打印按钮（横向、页眉页脚页码、隐藏界面元素） |
| WH-04/06/E-10 | 窄屏表格不可用 | 通用响应式表格：窄屏自动变卡片 |
| 多处 | 扫码框失焦丢码、串码 | 通用扫码输入框（保持焦点、失败清空、UDI/GS1 解析） |

### G1 平台与岗位工作台
- **E-14/D#17/WH-09/A15/C-F23**：业务数据按权限可读（财务、审计、价格、库存金额）；菜单、工作台 KPI、快捷按钮、待办按岗位裁剪；每个岗位有自己的首页（仓管九宫格、财务应收应付、管理员账号安全、QA 待审）。
- **E-09/A15/WH-09**：待办与 KPI 点进去带筛选；厂长“交付风险”卡（交期、进度、缺料、阻塞原因，红黄绿）；产出/FPY 可下钻；“待我审批”。
- **E-10/WH-14**：窄屏（<768）侧栏改抽屉、顶栏只留扫码条/铃铛/头像、触控目标 ≥44px。
- **E-16/WH-11**：全局搜索：唯一结果回车直接跳转；支持 UDI/GS1 原始串、领料/退料/盘点单号、库位、RMA；状态中文；仓管扫物料/批号跳库存。
- **E-02/E-24**：登录页演示账号下拉只在演示模式显示；记住上次账号；到期前 7 天提醒改密；PDA/工位空闲策略可按设备配置。

### G2 系统管理与数据导入
- **E-01 [P0]** 期初库存重复导入翻倍 → 按物料+库位+批号判重报错，可选覆盖；每次导入记批次可撤销；说明文字分实体。
- **E-02 [P0]** 预置账号公开密码 → 非演示初始化只建 admin 且首登强制改密；演示账号首登也强制改密；管理员首页提示“仍有 N 个初始密码账号”。
- **E-03** 管理员新建/重置的密码首登强制改密；生成随机临时密码；PIN 首次使用后自设。
- **E-07** 导入按实体分权限；页面提示当前账号可导入哪些数据；管理员上线迁移模式。
- **E-08** 审计追踪：BOM 等子表变更按行显示差异（物料编码、旧值→新值）；按单号/姓名查；详情页“变更记录”入口；导出。
- **E-12/E-13/E-22** 用户列表：账号列固定、状态前置、按角色/状态/部门筛选、默认新建在前；批量导入用户（Excel，输出初始密码清单）；批量分配角色/停用；行内解锁/重置/停用；停用释放工牌清 PIN；登录失败提示剩余次数。
- **E-15** 金蝶登录未启用时“金蝶账号”选项置灰并说明。
- **E-25/E-26/D#22** 导入模板说明与下拉、报错列出可选值、预检查；签名台账显示中文对象名、单号可点、可筛选导出。

### G3 销售 / 计划 / MRP
- **A1 [P0]** 已确认订单可变更：无下游时“反审核”回草稿；有工单时允许改数量/交期（校验已发货/已排产数量，提示受影响工单），全程留痕。
- **A2 [P0]** 订单生成工单与 MRP 转工单互不知情 → MRP 生产建议挂订单行（需求追溯），转工单关联订单；订单生成工单扣除已覆盖量；转单前检查 MRP 结果是否过期。
- **A3 [P0]** 重跑 MRP 重复建议已转单量 → 后续周已有在途/在制时给“提前催交”例外信息而非新建议。
- **A4/E-17** 齐套分析（无副作用）：订单和工单详情显示每个物料的需求、可用、缺口、在途采购单（可点）、预计到货；工单列表加齐套列。
- **A6** 明细行录入：行末回车新增一行（不删除）；删除需确认/可撤销；新建页焦点在第一个输入框。
- **A9** 订单生成工单按交期倒排开工；工单下达后数量/日期可调（未开工部分）。
- **A10** MRP：显示需求来源（订单/工单）、离散单位取整、说明折叠、可导出、转单前确认、历史单号可点。
- **A11** 同一客户 PO 号重复提示；复制订单；单价带出该客户上次成交价。
- **A12** 统一叫法（确认/审批/审核）；下推前预览。
- **A13** 销售可新建客户（或给出“找谁”）；产品下拉只列该客户品牌的产品。

### G4 采购 / 财务
- **A7** 已审批采购单可改交期/单价（留痕，可记录供应商回复交期）；**A8** 催货清单（未交数量、逾期天数、筛选排序、待办提醒）；按物料搜采购单。
- **A14** 采购可设采购单位（或物料采购属性由采购维护）；整卷取整不出现小数卷；未合格供应商提示中文并指明找质量部评审；供应商下拉显示合格状态。
- **A5** 订单/采购单打印（PI、采购单 PDF）。
- **E-04** 财务列表筛选（往来单位、期间、币别）、排序、导出；金蝶凭证引出模板。
- **E-05** 应收应付记账汇率与本位币金额；收款记实收汇率、手续费、汇兑差异；账龄按记账/期末汇率两种口径。
- **E-06** 收付款作废（原因+留痕）；超额提示预收；按客户合并收款自动分配。
- **E-19/E-20/E-21** 付款时显示来料 IQC 状态；汇率保存后刷新、被引用的汇率不可改、偏差过大确认；账龄币别小计、截止日、区间、下钻、导出。

### G5 工位终端 / 工程
- **C-F01 [P0]** 回车跳转随机失灵、数值拼接 → 修复焦点逻辑（倒计时重渲染丢输入框引用）；数字框只允许一个小数点；测试项小数位与合理范围；错误贴在输入框旁。
- **C-F02 [P0]** 测试项编码可重复 → 前端标红、后端拒绝（数据库唯一约束）。
- **C-F03** 无测试项工序“扫码即过站”或回车提交；**F04** 已过站/工序不符直接大字红色提示谁何时测过、送往哪道工序，不显示录入表；**F05** 全局键盘监听把扫码转给扫码框，工位模式隐藏全局搜索。
- **C-F06** 独立全屏工位模式，1280×800 不滚动；**F07** 退出工位需密码（工位专用账号）；**F08** 设备按适用工序校验（前后端），本工位工序首次由班组长设定。
- **C-F12–F18** PIN 页不误报、可自动提交；空闲锁定全屏提示+保留数据、本人回来只刷卡；终端设置限班组长；解锁时校验资质；关键件扫错清空；判不合格用不良代码按钮+确认；返工换件引导（从绑定/BOM 选拆下件）且必须先登记；字号/触控目标/整屏闪色+提示音。
- **C-F09** 工艺路线查看/审批页只显示两列（列宽 bug）；**F10** 离开页面未保存提示、变更原因只在提交时必填；**F11/D#2** 与上一版差异对比（新增/删除/修改分色，限值变化醒目），删除可确认/撤销，提交自动生成变更摘要；**F19** 测试项排序、OK/NG 型、小数位、作业指导图片/附件；**F21** BOM 重复组件当场提示；**F22** 过期仪器置灰；**D#18** BOM 生效日期生效（未到期前旧版继续生效）。

### G6 质量
- **D#5** NCR 处置期限与超期提醒、严重度/日期筛选、默认待处置、状态列前置。
- **D#6** 返工 NCR 复测合格后才能关闭（或自动关闭），关闭需签名。
- **D#7** “退货”处置不立即扣库存：生成退供应商单，仓管出库确认后扣账，通知采购。
- **D#8** IQC 定量项（上下限、逐件录值、自动判定）与定性项（需人工确认）；未完成项不能提交；不良数关联检验项。
- **D#9** 已完成检验单只显示建单时保存的内容。
- **D#10** 资质登记只列操作员（工牌号）、可扫工牌、选错警告、人员不可修改（作废重登）、登记需签名。
- **D#11** DHR 顶部“放行结论”卡（按序列号逐项：工序合格、无未关 NCR、返工已复测、用料已 IQC、设备在校准期、人员资质）；章节导航；过站记录折叠；签名区含 NCR 处置签名；分批放行签名说明列序列号。
- **D#12** 客诉法规字段：投诉人联系方式、事件日期、国家、是否上报/期限/编号、客户回复；“关闭”改“结案”。
- **D#13** 附件多选上传、预览、平板拍照、IQC 照片带到 NCR。
- **D#14/#16/#19/#20/#21/#23–27** IQC 提交后直接进入下一张待检单；抽样数字不折行；默认标准不与物料规格冲突；“放行”改“接收”；AQL 计算器自动重算；CAPA 附件/负责人/期限/关闭检查；检验规范排除免检物料、编号与版本；批量关闭 NCR；召回清单含 UDI/批号/联系人；放行中心“待放行数量”列。

### G7 仓储 / PDA
- **WH-02 [P0]** 库位校验：自有料不能进客供仓（后端拒绝）；MSL 物料进非防潮库位需确认；物料默认库位自动带出。
- **WH-03 [P0]** 盘点：同一仓/库位只允许一张进行中盘点单；过账按“实盘−当前账面”；快照后有流水提示；可作废。
- **WH-05** 拣料模式：扫库位/批号核对、改实拣数量、短缺自动从下一 FEFO 批次补足、部分过账。
- **WH-07/WH-20** PDA 收货作业页：竖排、回车跳下一项、同一 PO 行多批次。
- **WH-10** 盘点 PDA：扫码定位、卡片逐条录入、按库位排序、未盘按账面（确认）、可盲盘、按库位范围、可新增盘盈行。
- **WH-12/WH-13** RMA 与发货扫码复用同一解析（UDI/GS1 原始串）、失败清空保持焦点、扫 SN 带出客户订单；拒绝原因细分并加提示音；已扫清单在扫码框下、删除按钮够大；运单号可补录。
- **WH-15** 领料、发货、盘点冲销（反向单据、权限、原因、签名）。
- **WH-16/17/18/19/21** 调拨/上架扫码作业页（扫批号→扫库位）与待上架清单；“已有待过账领料单”提示；退料扫码定位；完工入库可选逐台扫码核对；“作废/返回”文案。
- **WH-08** 单据打印：入库单、批次标签、拣料单、发货单/装箱单、盘点表；库位标签。
