# 供应商协同（SRM）方案稿：全部自建

> 状态：方案稿，待采购、仓库、质量、财务与 2–3 家供应商代表确认后开发。
> 决定：不外购携客云等产品，在 Nuon 智造云内自建，数据与采购、收货、检验、应付共用一套。

## 1. 要解决的问题

1. 物料供应商多，每家外箱条码和信息格式不同，入库和盘点难以信息化。
2. 订单、交期、送货、对账、质量问题靠微信/电话/Excel 往来，没有记录，系统里的数据靠采购员和仓管转录。

原则：**供应商自己在门户里录入和打印，我们只做确认；货进门时已经带着我们格式的标签。**

## 2. 分期范围

| 期 | 内容 | 解决什么 |
|---|---|---|
| **一期**（与仓库 RFID 衔接） | 供应商账号与门户、采购单在线确认与交期回复、送货预约（ASN）、统一箱标打印、收货台按 ASN 一键收货、供应商条码解析规则（未上门户的供应商兜底） | 入库信息化、交期可见 |
| **二期** | 对账单在线确认、发票登记、付款进度查询；来料不良/退供应商单/8D 在线流转；资质证书到期由供应商上传更新（质量部审核） | 财务与质量协同 |
| **三期** | 询价比价、供应商绩效（交期达成率、来料合格率、响应时效）、年度评审、预测/备料计划共享 | 寻源与管理 |

## 3. 一期设计

### 3.1 供应商账号与隔离
- 新增用户类型“供应商账号”，绑定一家供应商（`User.supplier_id`），新角色 `supplier`，只有门户权限。
- **数据隔离在后端强制**：门户接口统一走 `/api/portal/*`，每个查询都带当前账号的 `supplier_id` 过滤；供应商账号访问内部接口一律 403。价格只显示本供应商自己的单价。
- 账号由采购在供应商主数据页开通（随机临时密码，首次登录强制改密，沿用现有密码策略与失败锁定）。
- 门户用独立的精简界面（`/portal`），不显示内部菜单。

### 3.2 采购单确认与交期回复
- 采购单审批后，供应商在门户看到“待确认订单”，可整单确认或逐行回复交期（写入 `PurchaseOrderLine.promised_date`，现有字段），可填备注。
- 回复交期晚于需求日期时，采购员待办出现“交期异常”；采购单变更后供应商须重新确认（记录确认人、时间）。
- 催货清单增加“供应商未确认”“回复晚于需求”筛选。

### 3.3 送货预约（ASN）与统一箱标
- 供应商按采购单行创建送货单：送货日期、每箱的物料、数量、**原厂批号、生产日期**、箱数；系统校验不超过未交数量。
- 提交后生成**箱标**（每箱一张，A6 或 100×70mm）：我方物料编码与名称、采购单号、原厂批号、生产日期、数量、箱号 n/N、二维码（内容为箱唯一号）。供应商自行打印粘贴。
- 可选：对配了 RFID 打印机的供应商，箱标同时写入 EPC（与仓库 RFID 标签同一套编码），到货过收货台即自动识别。
- 新模型：`Asn`（送货单：单号、供应商、采购单、状态 草稿/已提交/已到货/已取消、预计到货日）、`AsnBox`（箱：箱号、物料、批号、生产日期、数量、EPC、收货状态）。

### 3.4 收货台衔接
- 有 ASN：仓管在收货台扫任一箱标或读到箱 RFID → 带出整张送货单 → 逐箱核对（读到/缺少/多出）→ 确认生成入库单，批号、生产日期、数量直接取 ASN，不再手录。实收与 ASN 不符时按箱调整并记录差异。
- 无 ASN（未上门户的供应商）：走“供应商条码解析规则”——按供应商配置外箱条码模板（GS1、分隔符、固定位置、正则四种），加“供应商料号 ↔ 我方物料”对照表；扫供应商箱标自动拆出字段，仓管核对；解析不了则手工录入并提示配置规则。
- 两种情况收货后都发我方统一标签（RFID + 条码），库内只认我方标签。

### 3.5 推行办法
- 发《来料标签规范》给全部供应商（附门户操作手册）；先推采购额最大的 10–20 家，写入采购合同/质量协议。
- 系统统计每家的“ASN 覆盖率”（按到货批次），采购月度跟进。

## 4. 安全（门户对外网开放，必须单独做）
- 门户与内部系统同一后端，但内部接口对 `supplier` 角色全部拒绝；新增自动化测试逐个接口验证越权（A 供应商不能读 B 的任何数据）。
- 外网入口只暴露 `/portal` 与 `/api/portal/*`、登录相关接口；反向代理限流，登录加图形验证码或短信/邮箱二次验证（方式待定）。
- 供应商上传的文件（证书、8D）做类型与大小限制，存储与内部附件分目录。
- 所有门户操作进入审计追踪。

## 5. 需要业务方确认的问题
1. 门户登录的二次验证方式：短信、邮箱验证码，还是暂不启用？
2. 箱标尺寸与供应商是否普遍有标签打印机（没有的可用 A4 不干胶纸打印）。
3. 一期先推哪些供应商；是否把“按规范贴标/录 ASN”写入合同条款。
4. 供应商是否可以看到采购单价（建议可见本单价格，便于确认订单）。
5. 为设计条码解析规则，请提供 5–10 家主要供应商外箱标签的照片或扫描出的原始内容。

## 6. 与现有功能的关系
- 复用：供应商主数据与合格供方状态、采购单与变更记录、催货清单、收货与库位校验、IQC、退供应商单、应付与对账数据、RFID 标签。
- 不变：内部采购、仓库、质量、财务流程不因门户而改变；没有上门户的供应商仍按现有方式（加条码解析规则）处理。
